# Little Car Museum · 小小汽车馆

面向 3～8 岁儿童及家长的响应式汽车认知网站，让孩子通过旋转、缩放和切换视角观察汽车，认识汽车类型、颜色与外观部件。

> 当前阶段：需求与开发规范准备完成，尚未初始化应用。仓库目前没有 `package.json`、业务代码或可运行的开发服务。

## 项目文档

- [需求文档](./需求文档.md)：产品范围、功能规格、数据模型、开发任务及上线验收标准。
- [AGENTS.md](./AGENTS.md)：供大模型和开发者遵循的项目约束、实施流程、验证与交付要求。

## 计划功能

以下为开发目标，尚未实现：

- 按分类浏览汽车，查看基础品牌卡片。
- 3D 汽车加载、旋转、缩放、复位、预设视角及支持模型的车身换色。
- 模型加载失败时降级到多角度图片或封面。
- 本地收藏、最近浏览与名称语音。
- 管理后台维护分类、品牌、车辆、素材许可证和发布状态。
- 适配手机、平板和桌面，提供儿童友好的大按钮与清晰反馈。

MVP 上线至少需要 12 辆可展示汽车、6 个有已发布内容的分类，其中至少 8 辆支持 3D。完整上线条件以需求文档第 41 章为准。

## 开始开发

1. 阅读 `AGENTS.md` 和本次任务对应的需求章节。
2. 按需求文档第 35 章逐项实施，首先执行 `TASK-001`：初始化应用及开发工具。
3. 初始化完成后更新本 README，补充实际 Node.js 版本、环境变量、安装、运行和测试命令。

当前不要直接运行 `npm install` 或 `npm run dev`，应用配置尚未建立。后续计划提供 `dev`、`lint`、`typecheck`、`test`、`build` 脚本；实际用法以初始化后的 `package.json` 为准。

推荐开发顺序：基础工程 → 类型与占位数据 → 列表 → 3D 查看器原型 → 详情与本地记录 → 数据库和 API → 认证与后台 → 上传 → 性能兼容与完整验收。

## 内容与隐私原则

- 以授权明确的通用模型为主，不用通用模型冒充真实品牌量产车型。
- 所有第三方模型、图片、贴图、音频和 Logo 在发布前必须登记并审核授权；保留来源、署名与修改记录。
- 开发占位资源须明确标注，不能计入正式上线内容。
- MVP 不包含广告、支付、评论社区或儿童公开账号；收藏与最近浏览保存在浏览器本地。
- 密钥和真实环境配置不得提交；未来的 `.env.example` 仅使用占位值。
